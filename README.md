# romanecastel.github.io

Personal website of Romane Castel. A single static page (`index.html`) plus `cv.pdf`.

## Publish on GitHub Pages (about 5 minutes, all in the browser)

1. Go to https://github.com/new while signed in as **RomaneCastel**.
2. Repository name: **`RomaneCastel.github.io`** (must match your username exactly). Set it to **Public**. Click **Create repository**.
3. On the empty repo page, click **"uploading an existing file"**.
4. Drag in `index.html`, `cv.pdf` and this `README.md`. Click **Commit changes**.
5. Go to **Settings → Pages**. Under "Build and deployment", Source = **Deploy from a branch**, Branch = **main**, folder **/ (root)**. Save.
6. After 1–2 minutes the site is live at **https://romanecastel.github.io**.

## Updating it later

- **Edit text:** open `index.html` on GitHub, click the pencil icon, edit, commit. The site updates within a minute or two.
- **New CV:** upload a new file named exactly `cv.pdf` (it replaces the old one).
- **Add a project:** in `index.html`, search for `TEMPLATE for a new project`, copy that commented block, remove the `<!--` and `-->`, and fill it in.
